## 남은 보정

Figma Starter 플랜의 MCP 도구 호출 한도로 마지막 Input 폭 보정이 실행되지 않았습니다. 일부 Input 인스턴스의 내부 텍스트가 초기 컴포넌트 폭을 유지해 불필요하게 줄바꿈합니다. handoff.json의 remaining_work에 수정 방법과 예시 노드를 기록했습니다. 수정 후 입력 폼 및 컴포넌트·인계 페이지를 최종 재검수해야 합니다.

## 개발 범위

현재 산출물은 Figma Design 화면과 이동 프로토타입입니다. 인증, 업로드, PDF 생성, 통계 계산 및 실제 API 연결은 후속 개발에서 구현합니다. 숫자 판정은 코드로 계산하고, LLM은 가정과 검증 제안 초안만 작성합니다.

첨부 지시에서 2장 화면 목록과 레이어 접두어 정의가 누락되어 확정 기획과 제공된 예시를 기준으로 보완했습니다. 선택한 화면 키와 명명 규칙은 handoff.json에 기록했습니다.
